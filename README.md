# IronLog — веб-версия

Тренировки с таймерами отдыха, питание и аналитика. Работает в Safari на iPhone как приложение (Поделиться → «На экран Домой»), офлайн. Данные хранятся только на устройстве.

Без сборки: Preact + htm лежат в `js/vendor/`. Справочник упражнений и блюд (`js/seed-data.js`) выгружается из Android-версии.
